🔍PROBLEM 2 Find Largest Delta - Results by Rule

📖 Problem Definition

Given a fixed epsilon (ε = 30,000), find the largest delta (δ) where the rule is still heterogeneous (violations exist).

Interpretation: What's the maximum minimum subgroup size where we can still detect treatment effect differences?

⚙️ Algorithm Used

Binary Search with FPGrowth Oracle

  • Monotonicity property: If heterogeneous at δ, remains heterogeneous for all δ' < δ
  • Complexity: O(log(δ_max - δ_min)) oracle calls
  • Each oracle call uses FPGrowth to check all subgroups ≥ δ

🎯PROBLEM 3 Find Smallest Epsilon - Method Comparison by Rule

📖 Problem Definition

Given a fixed delta (δ = 1,000), find the smallest epsilon (ε) where the rule becomes homogeneous.

Interpretation: What's the minimum threshold needed to consider all subgroups "similar enough"?

⚙️ Methods Compared

🔎 Binary Search

Uses binary search with FPGrowth oracle to efficiently find the smallest ε.

Advantage: Fewer oracle calls (logarithmic complexity)

📊 Brute Force

Enumerates all subgroups once using FPGrowth and finds maximum difference.

Advantage: Guaranteed exact answer (no approximation)
